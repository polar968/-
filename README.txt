كُوخ إيلياء POS - النسخة النهائية

تم تحديث صور الأصناف باستخدام صور المنيو التي أرسلها المستخدم، مع قص صور الطعام/القهوة/القهوة الباردة/المشروبات/الكعك لاستخدامها داخل بطاقات الأصناف.
الفواتير تحفظ تلقائيًا بعد الدفع على نفس الجهاز، مع نسخة احتياطية واستعادة وطباعة وتقارير يومية.

قاعدة البيانات: IndexedDB محلية داخل التطبيق، مع حفظ نسخة متوافقة في localStorage. كل فاتورة تسجل التاريخ والوقت بالـ ISO، ويظهر توقيت حي داخل الواجهة.


v5 - حماية البيانات
- زر واضح "💾 نسخ احتياطي" في أعلى التطبيق.
- زر واضح "♻️ استعادة" في أعلى التطبيق.
- النسخة الاحتياطية تشمل الأصناف والأسعار وجميع الفواتير.
- اسم ملف النسخة يتضمن التاريخ والوقت.
- عند الاستعادة يظهر تحذير قبل استبدال البيانات الحالية.
- ينصح بعمل نسخة احتياطية يوميًا وحفظ الملف خارج المتصفح.
