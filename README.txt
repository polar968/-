كُوخ إيلياء POS — نسخة تدقيق وإصلاح
- تم تدقيق JavaScript نحويًا.
- الصور مضمّنة داخل المجلد images وتستخدم مسارات موجودة فعليًا.
- Service Worker يضمّن صور الأصناف للعمل أوفلاين.
- IndexedDB مع مزامنة كاملة (clear + rewrite) لمنع بقاء بيانات قديمة بعد الاستعادة.
- النسخ الاحتياطي والاستعادة تشمل الأصناف والأسعار وجميع الفواتير.
- التقرير والتوقيت المحلي يعملان من تاريخ/وقت الجهاز.
- تصدير Excel الحالي هو ملف HTML بصيغة .xls لفتحه في Excel، وليس XLSX أصليًا.
